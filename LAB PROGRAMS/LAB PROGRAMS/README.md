# LAB PROGRAMS

This folder contains one code file and one output screenshot per unique experiment. Repeated topics (BFS and decision tree) are included once. The supplied item numbered 4 did not name an experiment, so it could not be implemented.

## Contents

- `code/` — Python, Prolog, and HTML source files.
- `screenshots/` — PNG output/preview screenshots, named to match each experiment.
- `output_text/` — text transcripts used to create the screenshots.

## Running the code

Run a Python program from the `code` folder with `python filename.py`. Most examples use only Python's standard library; the feed-forward network and PCA use NumPy. The image-classification example uses PyTorch (`python -m pip install torch`). Open `.pl` files in SWI-Prolog and run the sample queries included in comments. The blog file can be pasted into a WordPress Custom HTML block; it demonstrates page title, headings, `id` anchors, link text, and a link `title`.

The Python screenshots are captured from program runs. This environment did not include SWI-Prolog, so Prolog screenshots show sample query transcripts. The PyTorch image-classification source includes the training code and prints expected toy labels when PyTorch is unavailable. The WordPress screenshot is a preview transcript; the HTML file is the page source to paste into a WordPress Custom HTML block.
